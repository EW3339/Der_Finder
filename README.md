# Der Finder

Browser-Tool zum Heraussuchen bestimmter Seriennummern aus vielen Teilen per Barcodescanner oder Handykamera.

Privatentwicklung! Ohne Gewähr! Idee: E.W. Code: C.C.

- PC: `index.html` herunterladen und im Browser öffnen, Scanner (Tastaturmodus mit Enter) anschließen.
- Handy: die GitHub-Pages-Adresse in Chrome öffnen und die Kamera erlauben.

Listen und Scans bleiben nur im Browser des jeweiligen Geräts.

Kamera-Erkennung: [html5-qrcode](https://github.com/mebjas/html5-qrcode) 2.3.8 (Apache-2.0), lokal eingebunden.
